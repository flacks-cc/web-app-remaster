## 🚀 Inicio rápido

### Requisitos previos

- Node.js 18+
- Angular CLI

### Instalación

```bash
git clone https://github.com/flacks-cc/web-app-remaster.git
cd web-app-remaster
npm install
ng serve
```

## 🧩 Tecnologías

| Capa | Tecnología |
